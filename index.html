Documentação da Linguagem Sabrosito

1. Introdução

A linguagem Sabrosito é um sistema de comandos desenvolvido para gerenciar um estoque e realizar vendas de produtos em um mercado. A linguagem foi projetada para ser simples e direta, permitindo que usuários interajam com um sistema de controle de estoque e vendas de forma eficiente.

Funcionalidades Principais:

  • Adicionar produtos ao estoque
  • Vender produtos
  • Consultar estoque
  • Alterar preços e quantidades dos produtos
  • Remover produtos do estoque
  • Gerar relatórios de vendas

2. Comandos Disponíveis

2.1. arepa [nome] [quantidade] [preço]

Adiciona um produto ao estoque com o nome, quantidade e preço especificados. Se o produto já existir, a quantidade será incrementada.

arepa Teclado 10 15.50

2.2. empanada [nome] [quantidade]

Vende um determinado número de unidades de um produto. O estoque será reduzido conforme as vendas.

empanada Teclado 3

2.3. buñuelo

Consulta e exibe todos os produtos em estoque, com suas quantidades e preços.

buñuelo
            
Estoque atual:
            
Teclado: 7 disponível(s), Preço unitário: R$15.50

2.4. pandebono [nome]

Consulta o preço de um produto específico.

pandebono Teclado
            
Preço de Teclado: R$15.50

2.5. bandeja_paisa [nome] [novo_preço]

Altera o preço de um produto específico no estoque.

bandeja_paisa teclado 50
            
Preço de teclado alterado para: R$50.00

2.6. empanadita [nome] [nova_quantidade]

Altera a quantidade de um produto no estoque.

empanadita arepa_americana 50

2.7. arepita [nome]

Remove um produto do estoque. O produto será excluído permanentemente.

empanadita Teclado 
            
Produto Teclado removido do estoque.

2.8. sancocho

Gera um relatório de vendas, exibindo o número de unidades vendidas de cada produto.

sancocho
            
Relatório de Vendas:
            
teclado: 3 unidade(s) vendida(s).

3. Estrutura de Dados

Produto

A estrutura de dados principal é a Produto, que contém as informações sobre cada produto no estoque. Ela é composta por:

typedef struct {
    char nome[50];       // Nome do produto
    int quantidade;      // Quantidade disponível no estoque
    float preco;         // Preço unitário do produto
    int vendas;          // Quantidade de vendas realizadas
} Produto;
  • nome: Nome do produto.
  • quantidade: Quantidade disponível no estoque.
  • preco: Preço unitário do produto.
  • vendas: Contador de vendas realizadas.

5. Conclusão

A linguagem Sabrosito é uma ferramenta simples e eficaz para gerenciamento de estoque e vendas, permitindo que os usuários possam adicionar, vender, consultar e modificar produtos de forma prática. Essa linguagem pode ser expandida para incluir novas funcionalidades conforme necessário.
